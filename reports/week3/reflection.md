# Week 3 Reflection

## Learning points
- We changed user stories from human users to system components. It was easier to describe tasks this way.
- We learned how MAVLink works and how to connect to SITL.
- We saw that for a robotics project, communication between parts is more important than a GUI.
- Closing issues and creating PRs with reviews helped us work in a structured way.

## Validated assumptions
- We thought we needed a Figma prototype. The customer said no. We use MAVLink docs instead.
- We thought we needed a video with a real airship. Not possible yet. We show SITL simulation.
- We assumed all Must Have stories would be done on time. Most were, except UWB and smoke-check.

## Friction and gaps
- No real hardware for testing (still not available).
- UWB integration is not finished.
- Smoke-check automation is not fully implemented.

## Planned response
- Finish UWB and smoke-check in the next sprint.
- Continue testing in SITL. Do not wait for hardware.
- Ask other team members to create Projects if needed.

## Updated status
All Must Have issues were closed before the deadline. US-14 (UWB) and US-22 (smoke-check) are still in progress but not blocking MVP v1.
