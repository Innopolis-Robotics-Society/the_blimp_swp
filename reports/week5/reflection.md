# Week 5 Reflection

## What we learned
- We learned how to document architecture using PlantUML diagrams.
- We learned how to write ADRs and link them to quality requirements.
- We learned how to describe our development process with a git diagram.
- We learned that we need to customize ArduPilot for Blimp (ArduMotorBlimp) instead of using stock Blimp.
- We learned that Windows support in documentation is not needed — it simplifies setup.

## What we confirmed
- Architecture documentation helps understand the system.
- ADRs help explain why decisions were made.
- The development process is clear and works for our team.
- Customer confirmed that custom ArduPilot vehicle is the right approach.

## Problems we faced
- Some diagrams were hard to draw without experience.
- Writing ADRs takes time.
- ArduPilot build system has some issues with custom vehicles.

## What we will do next
- Finish MVP v2 implementation.
- Coordinate with Capstone team on motor frames.
- Continue improving architecture documentation as the system grows.
