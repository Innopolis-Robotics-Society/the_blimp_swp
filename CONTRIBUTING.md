# Contributing to the_blimp_swp

Thank you for your interest in contributing to our project!

## How to contribute

1. **Find an issue** – check the [Issues](https://github.com/Innopolis-Robotics-Society/the_blimp_swp/issues) page.
2. **Comment on the issue** – let others know you are working on it.
3. **Fork or branch** – create a branch from `main` (e.g., `feature/your-feature-name`).
4. **Write code and tests** – follow our coding style.
5. **Run tests locally** – make sure everything passes.
6. **Open a Pull Request** – link it to the issue.
7. **Wait for review** – at least one team member must approve.

## Coding style

- Python: follow [PEP 8](https://pep8.org/).
- Use clear variable names.
- Write docstrings for functions.

## Testing

- Run `pytest tests/` to run all tests.
- Add tests for new features.

## Documentation

- Update `README.md` if you change setup or usage.
- Update `CHANGELOG.md` with your changes.

## Questions?

Ask in the team chat or comment on the issue.
