# Airship MAVLink Backend

Минимальный бэкенд на Python для управления автономным дирижаблем через протокол MAVLink. Обеспечивает связь между высокоуровневым планировщиком маршрутов и полётным контроллером (ArduPilot).

## 📋 Описание

Этот проект является частью разработки автономного дирижабля для indoor-навигации в атриуме университета. Бэкенд выполняет роль "моста" между:
- **Наземной станцией/планировщиком** (через REST API и WebSocket)
- **Полётным контроллером** (через протокол MAVLink)

### Основные возможности

- ✅ Приём телеметрии в реальном времени (позиция, батарея, статус)
- ✅ Отправка целевых точек (Guided mode)
- ✅ Загрузка миссий (AUTO mode) с подтверждением каждой точки
- ✅ REST API для интеграции с внешними системами
- ✅ WebSocket для стриминга телеметрии (10 Hz)
- ✅ Логирование всех событий в файл

## 🛠 Требования

- Python 3.9+
- Полётный контроллер с прошивкой ArduPilot (или SITL симулятор для тестов)
